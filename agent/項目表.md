# 專案地圖

- `agent/question.md`：用戶需求與驗收條件。
- `agent/deep_todos.md`：歷史任務與進度。
- `agent/memory.md`：重要讀寫與執行紀錄。
- `src/main/java/tw/cute/mcvm/McVmPlugin.java`：Paper 啟動入口，驗證設定後背景安裝。
- `src/main/java/tw/cute/mcvm/VmSettings.java`：資源與 SSH 公鑰驗證。
- `src/main/java/tw/cute/mcvm/DebianImageSource.java`：官方映像與 SHA-512 校驗。
- `src/main/java/tw/cute/mcvm/VmProvisioner.java`：磁碟、cloud-init ISO 與 QEMU 流程。
- `src/main/java/tw/cute/mcvm/SystemCommands.java`、`SystemVmState.java`：受逾時保護的命令與 Linux PID 辨識。
- `src/main/resources/`：Paper plugin.yml 與預設 config.yml。
- `src/test/java/tw/cute/mcvm/CoreTests.java`：16 項可執行測試；`src/test/java/org/bukkit/` 僅是測試替身，不進正式 JAR。
- `pom.xml`：Maven Java 8 編譯與測試入口。
- `.github/workflows/ci.yml`：Java 多版本、正式 JAR 內容與 Docker 工具的 push/PR 驗收。
- `.github/workflows/vm-integration.yml`：手動觸發的 Paper/Debian TCG 開機、SSH 與重啟資料持久化測試。
- `Dockerfile`、`compose.yaml`：含 QEMU 工具的容器與持久化部署範例。
- `.gitignore`：排除打包產物及含 VM 磁碟與 SSH 公鑰設定的 `data/`。
- `README.md`：部署、安全與環境限制。
